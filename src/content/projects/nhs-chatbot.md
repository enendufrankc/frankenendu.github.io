## Overview

Built at BCN Group for an NHS client. The application allows NHS staff to query the PublicView benchmarking database in natural language and receive generated performance reports as PDFs. Azure OpenAI handles the natural language understanding and report generation, with the PublicView API providing access to NHS performance metrics and benchmarking data.
