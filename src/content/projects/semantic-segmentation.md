## Overview

Semantic segmentation model trained on the Cambridge Labeled Objects in Video (CamVid) dataset for autonomous driving perception. Performs pixel-level object classification — assigning each pixel a class label such as road, pedestrian, vehicle, or sky. Implemented in TensorFlow/Keras with OpenCV for preprocessing. Write-up published on Medium.
